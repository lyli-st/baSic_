# baSic_ v1.0

x86 kernel built from scratch in C and assembly.

## Build & Run

```bash
# cross-compiler is recommended 
sudo apt install nasm qemu-system-x86 
# prebuilt cross toolchain(for some PCs)
sudo apt install gcc-i686-linux-gnu
make run
```
